4. Pure Markdown Callout Boxes (IAL Styles)If you hate writing raw HTML <div> blocks or blockquotes (>), you can style plain text paragraphs instantly into custom, color-coded alert containers. Simply write your text, and append the selector class on the line immediately following it.
Tip Box (Green)This is an extraction success tip. Perfect for highlighting quick shortcuts, handy commands, or CTF hints.
{:.box-tip}Info Box (Blue)This is a standard information box. Use this to provide background context or reference technical RFC specifications.
{:.box-info}Warning Box (Orange)This is a warning notification. Great for advising readers about unstable environments or easily missed configuration flags.
{:.box-warning}Danger Box (Red)This is a high-risk security alert. Excellent for warnings regarding rate-limits, active firewalls, or commands that might crash a local service.
{:.box-danger}

Chirpy has built-in support for rendering math equations beautifully. Use single $ for inline formulas, and double $$ for block-level formulas.
