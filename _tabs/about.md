## Hey, I'm Ekansh 👋

I'm a Computer Science student who likes building things, breaking things (safely, mostly), and writing down whatever I learn along the way so future-me doesn't forget it.

### What this blog is about

This started as a place to dump my OverTheWire wargame writeups — Bandit, Leviathan, Natas, and whatever else I end up poking at. Most of these were written *while* I was solving them, so expect a bit of trial-and-error, some "wait why didn't this work" moments, and the occasional `#Mistake?!` along the way. I've gone back and cleaned a few up to be a bit more readable, but I've kept the "figuring it out as I go" tone intentionally — that's how the learning actually happened.

### What I'm into

- **C++ and Python** — mostly DSA practice and small projects
- **Linux and systems** — I run Arch with Openbox, Polybar, Picom, the whole terminal-first setup
- **Security, as a hobby** — OverTheWire, TryHackMe, HackTheBox, whatever helps me understand how things break

I'm aiming for a software engineering path, but honestly the systems/security rabbit hole is too fun to leave alone.
