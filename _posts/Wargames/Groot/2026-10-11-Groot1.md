## Objective :

The password for groot2 is the last five alphanumeric characters of the MD5 hash of this system’s hosts file.

## Solution : 

A quick google shows us that on Windows , the system's hosts file is stored at : `C:\Windows\System32\drivers\etc\hosts` 
Hence we go into that directory. Check for the file. And then using the `Get-FileHash` function check the MD5 hash of the `hosts` file as follows :

PS C:\> cd $env:SystemRoot                                                                                                                                                                  
PS C:\Windows> cd System32
