## Objective :

The password for groot7 is the name of the program that is set to start when this user logs in PLUS the name of the file on the desktop.

## Solution :

We check for the file name present on the desktop as follows : 

```powershell
PS C:\users\Groot6\desktop> gci                                                                                                                                                             
                                                                                                                                                                                            
                                                                                                                                                                                            
    Directory: C:\users\Groot6\desktop                                                                                                                                                      
                                                                                                                                                                                            
                                                                                                                                                                                            
Mode                LastWriteTime         Length Name                                                                                                                                       
----                -------------         ------ ----                                                                                                                                       
-a----        8/21/2020   1:24 PM              0 _rules                                                                                                                                     
                                                                                                                                                                                            
                                                                                                                                                                                            
PS C:\users\Groot6\desktop>     
```

And then we check for the Startup programs present for the user. We perform this using our previous knowledge of the Century and Cyborg levels. 

```powershell
PS C:\users\Groot6\desktop> Get-CimInstance Win32_StartupCommand                                                                                                                            
                                                                                                                                                                                            
Command          User                Caption                                                                                                                                                
-------          ----                -------                                                                                                                                                
                 underthewire\Groot6 New Value #1                                                                                                                                           
                 underthewire\Groot6 New Value #2                                                                                                                                           
                 underthewire\Groot6 New Value #3                                                                                                                                           
                 underthewire\Groot6 New Value #4                                                                                                                                           
C:\star-lord.exe underthewire\Groot6 star-lord                                                                                                                                              
                                               
```

Hence the password for the next level is : `star-lord_rules`
