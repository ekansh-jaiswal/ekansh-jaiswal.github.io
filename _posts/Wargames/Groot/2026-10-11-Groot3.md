## Objective :

The password for groot4 is the number of times the word “beetle” is listed in the file on the desktop.

## Solution :

We find the file on the desktop and then use the `Select-String` function to check for the pattern "beetle" present inside the file. 

```powershell
PS C:\users\Groot3\desktop> gci                                                                                                                                                             
                                                                                                                                                                                            
                                                                                                                                                                                            
    Directory: C:\users\Groot3\desktop                                                                                                                                                      
                                                                                                                                                                                            
                                                                                                                                                                                            
Mode                LastWriteTime         Length Name                                                                                                                                       
----                -------------         ------ ----                                                                                                                                       
-a----        8/30/2018   5:52 AM        2357296 words.txt                                                                                                                                  
                                                                                                                                                                                            
                                                                                                                                                                                            
PS C:\users\Groot3\desktop> $text = gc .\words.txt -Raw                                                                                                                                     
PS C:\users\Groot3\desktop> $count = $text | Select-String -Pattern "^beetle*" -AllMatches -CaseSensitive                                                                                   
PS C:\users\Groot3\desktop> $count.count                                                                                                                                                    
0                                                                                                                                                                                           
PS C:\users\Groot3\desktop> $count = $text | Select-String -Pattern "^beetle$" -AllMatches -CaseSensitive                                                                                   
PS C:\users\Groot3\desktop> $count.count                                                                                                                                                    
0                                                                                                                                                                                           
PS C:\users\Groot3\desktop> $text = more .\words.txt                                                                                                                                        
PS C:\users\Groot3\desktop> $count = $text | Select-String -Pattern "^beetle$"                                                                                                              
PS C:\users\Groot3\desktop> $count.count                                                                                                                                                    
0                                                                                                                                                                                           
PS C:\users\Groot3\desktop> $count = $text | Select-String -Pattern "beetle"                                                                                                                
PS C:\users\Groot3\desktop> $count.count                                                                                                                                                    
5                                                                                                                                                                                           
PS C:\users\Groot3\desktop>                                                                                                                                                                 
                              
```

Hence the password for the next level is : `5`
