## Objective :

The password for Century14 is the number of words within the file on the desktop.

## Solution : 

Using the knowledge from the previous Century's challenges we perform the following : 

```powershell
PS C:\users\century13\desktop> $text = more .\countmywords                                                                                                                                  
PS C:\users\century13\desktop> ($text -split '\s+').count                                                                                                                                   
756                                                                                                                                                                                         
PS C:\users\century13\desktop>  
```

Now if we directly put `756` in there , we see that the answer is incorrect , but we if check the index one by one we notice we have an special character hiding in place. 

```powershell
[ . . . ]
sts corkwing astrictiveness frontispieces copetitioner nonabidingness quartersawing unremarkable paco lochiocyte nonrepentant cheerly apoise misplant stan versifiaster shellapple enzymes  
                                                                                                                                                                                            
PS C:\users\century13\desktop> ($text -split '\s+')[756]                                                                                                                                    
PS C:\users\century13\desktop> ($text -split '\s+')[755]                                                                                                                                    
                                                                                                                                                                                            
PS C:\users\century13\desktop> ($text -split '\s+')[754]                                                                                                                                    
enzymes                                                                                                                                                                                     
PS C:\users\century13\desktop>      
```

So the answer is 755 as the password for the next level.
