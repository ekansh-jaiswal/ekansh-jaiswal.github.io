## Objective : 

The password for Century4 is the number of files on the desktop.

## Solution : 

Since I had no idea, I had to figure this out via Stackoverflow. I have shared the link below for the chat :

Link : https://stackoverflow.com/questions/14714284/count-items-in-a-folder-with-powershell

And the solution now becomes : 

```powershell
PS C:\users\century3\desktop> Write-Host (Get-ChildItem $pwd | Measure-Object ).Count                                                                                                      
123                                                                                                                                                                                        
PS C:\users\century3\desktop> (Get-childitem $pwd).count                                                                                                                                   
123                                                                                                                                                                                        
PS C:\users\century3\desktop>  
```

Both these commands gave me the same output. 
I realized the commands were much simpler than the one on stackOverflow. I mean let's understand the 2nd command which i ran and made : 

- `Get-ChildItem` : Shows the contents of the directory we are in. 
- `$pwd` : I used the current working directory keyword as a variable. Instead of typing everything. 
- `.count` : Shows the count , or basically how many contents are present in the selected directory.
