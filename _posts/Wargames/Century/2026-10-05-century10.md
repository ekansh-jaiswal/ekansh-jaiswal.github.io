## CMI v/s WMI : 

The Evolution: WMI(Windows Management Instrumention) vs. CIM(Common Information Model)
You might hear people talk about WMI (Windows Management Instrumentation) in older scripting tutorials.

• WMI was Microsoft's old, clunky, proprietary version of this map. It used an outdated protocol (DCOM) that was notoriously hated by system administrators because it constantly blocked firewalls.
• CIM is the modern replacement. It uses standard web protocols (WS-Management/HTTP). It is fast, clean, secure, firewall-friendly, and works across Windows, Linux, and Mac.

Windows PowerShell 5.1's native Get-Service command is built on old, limited code that completely forgets to grab the description field from the OS registry.

Since I didn't understood how the CMI works from the docs , I asked Gemini to explain me with the following : 
Prompt : 

```text
what is this class thing that we pass in CIMInstance?? And how to put the name of a service in it instead?
```

Solution : 

```text
The Class (specifically -ClassName) is like telling PowerShell which table or folder in the master database it needs to open.
Think of the database like Excel:
• Win32_Service is the name of the entire sheet that holds all services.
• It is a template or structural definition. You cannot change -ClassName to a service name like wuauserv because wuauserv isn't a database table; it is just one single row inside the Win32_Service table.
How to look up a service by name inside the class
To specify the name of the service, you keep the -ClassName as Win32_Service and use the -Filter parameter to search for your specific row.
Here are the two ways to write it:
Option 1: The Fast Way (Using -Filter)
This tells the database engine to only give you the row where the Name column equals 'wuauserv'.
powershell
Get-CimInstance -ClassName Win32_Service -Filter "Name = 'wuauserv'"
Use code with caution.
Option 2: The Pipeline Way (Using Where-Object)
If the -Filter syntax feels confusing with its single and double quotes, you can pull the entire list of services and use PowerShell's pipeline to grab the name instead.
powershell
Get-CimInstance -ClassName Win32_Service | Where-Object Name -eq "wuauserv"
Use code with caution.
Why can't we just type the service name directly?
Every single row in the Win32_Service table has identical columns (like Name, Status, Description, and StartMode).
By passing Win32_Service to -ClassName, you are telling PowerShell: "Hey, prepare a bucket that expects these exact service properties." Then, the -Filter parameters pinpoints exactly which row drops into that bucket.
```
