So let's understand this before moving furthur : 

1. We make a variable hold the contents of the text file first using the `$text = more .\Word_File.txt` command. the name of the variable is `text`. 
2. Then we use the Powershell **operator** called `-split` to chop a single string into a list of smaller string based on a seperator.
3. `'\s+'` means that if there are even multiple spaces between words they won't get confused and powershell treats them all as a single operator. Here `\s` means whitespace and `+` means one or more.
4. After the split happens, our text become a list / array from which we can print objects. Such as shown in `($text -split '\s+')[1]`
5. Now we run `($text -split '\s+')[160]` to get the 161st word and we get the password!!

#### Difference betweeon Operators and Functions : 

You see while thinking about this I remember that in programming when we call a function it typically looks like 
`object.function(parameter)` So why didn't we did the same here when we called "Split" ?? 
The thing is that both Operators and Functions are different. 
Functions a.k.a Method use the structure I just mentioned while Operators take 2 parameters. 
One at the Left and another at right, so a typical operator would look like : 
```
[Left Parameter]    -split       [Right Parameter]
```
