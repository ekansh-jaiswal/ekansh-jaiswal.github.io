## Objective :

The password for Century12 is the name of the hidden file within the contacts, desktop, documents, downloads, favorites, music, or videos folder in the user’s profile.
(Important Note : - Exclude “desktop.ini”.
- The password will be lowercase no matter how it appears on the screen.)

## Solution : 

Using the Powershell Manual we run the follwing command using the User's Directory as the Home directory and search recursively for all hidden files available under it as follows : 

```powershell
PS C:\users\century11> Get-ChildItem -Path "C:\Users\century11" -Hidden -Recurse -Force  
[ . . . ]
    Directory: C:\Users\century11\Downloads                                                                                                                                                 
                                                                                                                                                                                            
                                                                                                                                                                                            
Mode                LastWriteTime         Length Name                                                                                                                                       
----                -------------         ------ ----                                                                                                                                       
--rh--        8/30/2018   3:34 AM             30 secret_sauce   
```

Here in the `--rh--` means the file is `read-only` and `hidden`, so let's go and see that. 

```powershell
PS C:\users\century11\Downloads> Get-ChildItem -Hidden                                                                                                                                      
                                                                                                                                                                                            
                                                                                                                                                                                            
    Directory: C:\users\century11\Downloads                                                                                                                                                 
                                                                                                                                                                                            
                                                                                                                                                                                            
Mode                LastWriteTime         Length Name                                                                                                                                       
----                -------------         ------ ----                                                                                                                                       
--rh--        8/30/2018   3:34 AM             30 secret_sauce                                                                                                                               
                                                                                                                                                                                            
                                                                                                                                                                                            
PS C:\users\century11\Downloads> more .\secret_sauce                                                                                                                                        
Congratulations. You found it!                                                                                                                                                              
                                                                                                                                                                                            
PS C:\users\century11\Downloads>   
```

There we go!! :)
