## Objective :

The password for Century15 is the number of times the word “polo” appears within the file on the desktop.

## Solution : 

We check for the file name on the desktop 

```powershell
PS C:\users\century14\desktop> ls                                                                                                                                                           
                                                                                                                                                                                            
                                                                                                                                                                                            
    Directory: C:\users\century14\desktop                                                                                                                                                   
                                                                                                                                                                                            
                                                                                                                                                                                            
Mode                LastWriteTime         Length Name                                                                                                                                       
----                -------------         ------ ----                                                                                                                                       
-a----        8/30/2018  11:24 PM         202900 countpolos                                                                                                                                 
                                                                                                                                                                                            
                                                                                                                                                                                            
PS C:\users\century14\desktop>  
```

THe content of it contains a lot of random words with the word "polo" appearing in between them. 
Using the understanding from previous Century levels, I devise a plan to split the words into array and then use the `Select-String` Function on them. 
Using reference from the manual and `Get-Help Select-String -full` I was able to understand how to use the `Select-String` function. 

```powersshell
PS C:\users\century14\desktop> $text = more .\countpolos                                                                                                                                    
PS C:\users\century14\desktop> $text2 = $text -split '\s+'                                                                                                                                  
PS C:\users\century14\desktop> $count_polo = $text2 | Select-String -Pattern "polo" -AllMatches -CaseSensitive                                                                              
PS C:\users\century14\desktop> $count_polo                                                                                                                                                  
                                                                                                                                                                                            
polo                                                                                                                                                                                        
polo                                                                                                                                                                                        
polo 
[ . . . ] 
anthropologies 
[ . . . ]
```

So we can see that we are getting the word "polo" but it also contains some cases where polo is part of the word itself rather than being the word itself. 
Upon Googling I found out a smarter way to use the same `Select-String` method : 

```powershell
PS C:\users\century14\desktop> $count_polo2 = $count_polo | Select-String -Pattern "^polo$"                                                                                                 
PS C:\users\century14\desktop> $count_polo2 
polo
polo
polo
[ . . .]
PS C:\users\century14\desktop> $count_polo2.count                                                                                                                                           
153                                                                                                                                                                                         
PS C:\users\century14\desktop>   
```

Here the twist is the use of `^` & `$` which basically means the "start" and "end" of the string respectively. 
So the statement `Select-String -Pattern "^polo$"` effectively means to search for Words in the text where the string begins with the pattern itself and also ends with the same pattern.
For example : 
"polo" begins and ends with the pattern of "polo" but "anthropologies" doesn't ends or begins with the pattern.
